# Three-minute demo script

**0:00–0:20** — Models generate answers, but teams lose the lessons behind them. Engram is persistent, governed engineering memory.

**0:20–0:55** — Record the approved CockroachDB refresh-token decision. Open Memory Explorer to show the ADR, rejected Redis approach, and security constraint with evidence.

**0:55–1:25** — Record INC-104. Show the extracted incident and confirmed serializable-transaction repair linked to the ADR.

**1:25–2:05** — Start a visibly new session. Ask about intermittent logouts during parallel refresh. Engram recommends the prior successful repair without repeated context.

**2:05–2:30** — Focus on Memory Trace: similarity, importance, recency, confidence, status, final score, selection reason, and evidence.

**2:30–2:45** — Show ADR-029 in Timeline, then preview consolidation. History and provenance remain intact.

**2:45–3:00** — Show CockroachDB vector memory, Bedrock reasoning, Lambda consolidation, and S3 evidence. Models generate answers. Engram preserves engineering experience. CockroachDB makes that memory durable, searchable, and production-ready.
